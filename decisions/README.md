# Decisions

This directory contains decision records for the project.

## Structure

- Architecture Decision Records (ADRs) are stored in `../docs/adr/`
- Other project decisions can be added here as needed.

## Template

Use the following template for new decisions:

```markdown
# Decision Title

## Status
Proposed / Accepted / Superseded

## Context
...

## Decision
...

## Consequences
...
```
